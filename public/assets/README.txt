KCC website prototype — assets folder
======================================

Drop sponsor / partner logo files here.

STAD GEEL LOGO (Foundational Sponsor)
-------------------------------------
The sponsors page (sponsors.html) is already wired to load the City of Geel
logo automatically. Just add the official file here with one of these names:

    stad-geel-logo.svg     (preferred — scales perfectly, any size)
    stad-geel-logo.png     (fallback — use a transparent background, ~600px+ wide)

The page tries the SVG first, then the PNG, and shows the text "Stad Geel"
until a file is present. No code change needed once the file is added.

Notes
-----
- Use the official logo file supplied by the City of Geel with their permission.
- Keep the original colours; place on the white panel (already set up).
- If the city provided usage guidelines (clear space, mono version), follow them.
- Partner logos (the four "YOUR LOGO" slots) can also be dropped here later and
  wired in the same way.
